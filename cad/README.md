# cad/

CAD-Modelle, Zeichnungen und Zuschnittlisten der Box (Mechanik).

Geplanter Inhalt:

- 3D-Modell der Box (40 × 30 × 50 cm) mit allen Komponenten (M2)
- Zuschnittliste und Zeichnungen mit Maßen (M2)
- Druckdateien für Halterungen (M8, M9)

Große Binärdateien bitte als exportiertes Format (z. B. STEP, STL, PDF) ablegen, damit man sie auch ohne CAD-Programm öffnen kann.
